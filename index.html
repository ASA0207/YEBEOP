CODE 01

상호 존중 및 예의 준수

모든 멤버에게 존중하는 태도를 유지해주세요. 비속어, 은어, 저속한 표현 및 타인 비방은 금지됩니다.

CODE 02

논란 및 분쟁 유발 금지

민감한 주제로 논란을 일으키거나 편가르기를 하는 행위는 엄격히 제한됩니다. 개인 갈등은 개인 메시지로 해결하거나 관리진에게 제보해주세요.

CODE 03

도배 및 홍보 금지

텍스트, 이모지, 멘션(@) 등을 악의적으로 도배하는 행위는 제한됩니다.

CODE 04

여미새 · 남미새 행위 엄격 금지

과도한 이성 집착과 불쾌한 구애는 금지합니다. 동의 없는 개인정보 요구 및 성희롱적 발언 적발 시 경고 없이 즉각 추방(밴)됩니다.

CODE 05

불법 및 유해 콘텐츠 제한

음란물, 혐오감을 주는 사진·영상 공유 시 경고 없이 즉각 차단(밴)될 수 있습니다.

CODE 06

1대1 만남 안내

개인 간 1대1 금전거래 및 사적 만남 등에 대해서는 길드에서 어떠한 책임도 지지 않습니다.
